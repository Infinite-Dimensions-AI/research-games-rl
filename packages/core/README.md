# Clean-room browser learning engine

Implements a small deterministic original platform environment and an educational NeuroEvolution of Augmenting Topologies-inspired algorithm. Independent mathematical implementation; does not reproduce the Lua program or Nintendo game data. First versions intentionally prioritize learnability, inspectable genome graphs and deterministic baselines over throughput. Node add/split innovations, speciation, aligned crossover, mutation, fitness sharing and reproduction are implemented. See methodology docs for differences from canonical NEAT.
