# Roadmap

For the authoritative Orchestra plan, see [todo.md on GitHub](https://github.com/Infinite-Dimensions-AI/research-games-rl/blob/main/todo.md).

- **M0:** local public monorepo with typed packages, Changesets, VitePress, and version-control workflows.
- **M1:** clean-room NEAT agent, original platformer, deterministic tests and browser visualization.
- **M2:** methodological validation, multiple seeds, baseline agents, canonical NEAT comparison and level generalisation.
- **M3:** extensible environments and game gallery, replay/checkpoints, reproducible result export.
- **M4:** optional WebGPU compute training improvements and dedicated profiling.
- **M5:** optional Python/Gymnasium and Stable-Baselines3 experiments; later research track.
